# macOS & iOS apps

Personal apps for Mac and iPhone.

| App | Open | What it does |
|---|---|---|
| [`habit-journal/`](habit-journal/) | **https://raphschweiger-dev.github.io/macos-ios-apps/** | Daily habit and outcome journal. Finds which habits actually affect things like skin redness or energy (lagged correlations with FDR correction). Syncs between Mac and iPhone through a private GitHub repo. |

Every push to `main` runs the tests, builds the app and deploys it to GitHub Pages (`.github/workflows/pages.yml`).
